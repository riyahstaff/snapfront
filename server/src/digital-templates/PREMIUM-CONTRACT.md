# Snapfront premium revision-2 digital layouts

Write only your assigned JSON file in `premium/<id>.json`. Keep id/format. Existing revision-1 files remain unchanged. Exactly ten designs per format (guide/checklist/hooks/quotes/planner), all distinct compositions, not palette swaps.

## Visual intent
Liquid Chrome luxury: art-directed metallic sculptural imagery, spacious charcoal or immaculate stone paper, contemporary confident display/serif contrast, architectural lines, chrome plaques, asymmetry. This is NOT a cream document with circles. Covers should look like collectible editorial releases or designer workbooks. Interiors should look thoughtfully typeset and useful with crisp boxes, writing lines and readable copy, never low-contrast decoration over text. Target modern consumers in 2026. Original Snapfront brand/artwork only.

## Base schema
Use existing template's complete fields as structural guide; replace its design and sample copy entirely. Fields: `id,format,name,description,tags,palette,fonts,cover,interior,sample`. New field `design_revision:2`.
Palette roles `paper,ink,accent,muted,soft`: six-digit hex. Paper/ink contrast >=4.5, paper/muted >=3 (paper can be dark but writing pages should stay usable). Fonts heading `sans|serif|display|mono`, body `sans|serif`. Name <=70, description <=240, tags <=8 <=40 chars. Sample fields title/subtitle/brand/eyebrow nonempty <=180 chars. Titles should feel aspirational/useful, NOT 'Editable template' or repeated same boilerplate. Quote sample should be the actual short memorable quote. Brand should say 'YOUR BRAND', editable, no made-up affiliation.

Cover: `background` role, `textColor` `ink|paper`; fields `title,subtitle,eyebrow,brand` boxes `{x,y,w,h,size,align}` in normalized 0..1 coordinates, entirely within canvas. Non-overlapping text boxes, no art or decoration obscuring text. Title font size 28..86, subtitle 11..20, eyebrow/brand 8..14; align left/center/right. At least 3 shapes, <=36. `image` may be normalized box or null, seller image overrides primary artwork inside that box; if used ensure this is a considered visual slot, not covering text.

Optional `cover.fieldColors`: role per field (`paper|ink|accent|muted|soft`). Apply only where contrast against actual solid region is >=4.5. Optional `cover.gradient`: `{from:<role>,to:<role>,direction:'vertical'|'horizontal'|'diagonal'}` full-page gradient before art, default background if omitted. Gradients are rendered identically in PDF and SVG. Artwork comes after gradient and BEFORE shapes/text, so use solid opaque text plaques where needed.

Optional `cover.artworks` array max3: each `{id:'chrome-gateway'|'pearl-sculpture'|'amethyst-glass'|'emerald-architecture'|'optical-silver',x,y,w,h,fit:'cover'|'contain',opacity:0..1}`. Original images are portrait 3:4; preserve subject unless deliberate art-directing crop. Choose different composition/framing versus other designs. Every template requires >=1 artwork. Original image is built into real render/export, never just a thumbnail. Match `cover.image` to main artwork region if seller should replace it, leave no overlap with text. Prefer contain for complete sculptures or cover for material crops. Text remains genuinely editable. `document.show_artwork` defaults true; false hides artwork. Uploaded image replaces first artwork region, remaining decorative artworks optional. Do not add arbitrary filesystem/URL references.

Shapes: `{kind:'rect'|'ellipse'|'line'|'arc'|'polygon',x,y,w,h,fill:<role>,opacity?,stroke?:0..6,radius?:0..0.1,points?:[[0..1,0..1]...],start?,end?}`. Line x/y start, w/h positive delta. Polygons 3..8 relative points. Arc angles -360..720. No invented shape fields or unbounded paths. Rich geometry can frame artwork but do NOT reuse identical placement; use asymmetric stripes, optical rules, chrome-label fields, split compositions, corner framing. Avoid obvious repeated circle + centered title motif.

Interior: margin34..60, headingSize22..34,bodySize10..12.5,lineHeight1.35..1.65,headerStyle `rule|band|side|stack|pill`, blockStyle `plain|cards|stripe|outline|steps`, column `single|sidebar`, numberStyle `plain|pill|large|none`, shapes max12 supported above. Optional `chapterStyle:'editorial'|'technical'|'gallery'` enables premium numbered-chapter header (renderer keeps content readable and measured). Optional `ornament:'chrome-rule'|'split-rail'|'micro-grid'|'none'` adds restrained real page furniture in margins only, NOT over body content. Optional `interior.gradient` same format, VERY subtle readable paper only. No full-page art behind reading copy.

## Output
Write complete standalone JSON. No Git/deployment/native/provider changes. Report assigned id,name,path,art direction,composition summary,interior summary. Do not generate images: parent has original art in progress. Review your chosen actual normalized boxes for text/art overlap and contrast. Independent work only on assigned file.
